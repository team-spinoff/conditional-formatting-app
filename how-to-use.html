How to Use

Set up your first formatting rule in under 30 seconds

Quick Start

1

Add the Board View

Open any board in monday.com. Click the + button next to your existing views (Main Table, Kanban, etc.) and select Conditional Formatting from the list of available views.

2

Create a Rule

Click the "Add Rule" button in the toolbar. A side panel opens where you can configure your formatting rule:

  1. Column: Select which column to evaluate (e.g., Status, Priority, Budget)
  2. Operator: Choose a comparison (equals, greater than, contains, between, overdue, etc.)
  3. Value: Enter or select the value to match against
  4. Color: Pick from 25+ preset colors or enter a custom hex code
  5. Mode: Choose "Cell Color" or "Row Highlight"

Click Save Rule and your board updates instantly.

3

Fine-Tune

Add more rules, drag to reorder priority, and use column shading to visually group your data. Rules are evaluated top to bottom — the first matching rule wins.

Tip: Place your most specific rules at the top and general/fallback rules at the bottom.

Features

Cell Coloring

Colors the background of individual cells that match your condition. Great for status indicators, number thresholds, and date-based alerts.

Row Highlighting

Highlights the entire row when the condition matches. Use this to make critical or overdue items stand out across all columns. Available on Starter plan and above.

Column Shading

Apply a background color to an entire column for visual grouping. Click the column shade icon in the column header to pick a color. Free plan: up to 5 shaded columns.

Cross-Column Rules

Set a condition on one column but apply the color to a different column. For example: "When Status = Stuck, color the Owner column red." Available on Pro plan.

FAQ

Do other users see my formatting rules?

Formatting rules are stored per-view. Anyone who opens the same Conditional Formatting view on the board will see the same rules and colors.

Does the app modify my board data?

No. The app only reads your board data to evaluate rules. It never writes, modifies, or deletes any items, columns, or values. Colors are applied visually in the view only.

What happens when I uninstall the app?

All stored formatting rules are removed. Your board data is never affected.

Can I use it on multiple boards?

Yes. Add the Conditional Formatting view to as many boards as you like. Each board has its own set of rules.

Does it work with subitems?

Subitem support is planned for a future update.
